# Royal Musician 音樂家

*A collaborative project by roylin1003 and Claude.*

古典名曲合成試聽台。曲譜是資料、音色是現場合成——同一份曲譜，可以奏出
**8-bit 版**（方波街機）、**水晶版**（音樂盒）、**鋼琴版**（泛音合成）三種聲音。
純 HTML5 + WebAudio，零音檔、零下載、不需安裝、不需伺服器——打開網頁就能聽。

**▶ 立即遊玩**：（上架後回填）

> 目前為 **alpha 測試版**。曲庫與音色仍在擴充中，歡迎回報「這首聽起來不對」。

---

## 操作

| 動作 | 功能 |
|---|---|
| 點音色按鈕 | 切換 8-bit 版／水晶版／鋼琴版 |
| 點曲名卡片 | 開始播放；播放中點別首直接換曲 |
| 播放中換音色 | 同一首立刻換聲——這一頁就是來比音色的 |
| 停止 | 停止播放 |

## 曲庫（12 首，全部公版）

歡樂頌、卡農、小夜曲、土耳其進行曲、命運交響曲、給愛麗絲、
小步舞曲、驚愕交響曲、晨歌、小星星變奏曲（沒錯，小星星是莫札特）、天國與地獄・康康舞、天國與地獄序曲。

所有曲目皆為公有領域作品（作曲家歿逾 70 年），旋律自行打譜、
音色由 WebAudio 即時合成——不使用任何錄音檔，無任何版權疑慮。

## 這是什麼

一具「曲譜資料 × 音色合成」的音樂引擎：一首曲子只是幾 KB 的音符資料
（`[音名, 拍數]`），想加一首就多寫一行。它是之後「古典名曲辨認遊戲」的地基——
只播前幾拍猜曲名，用音樂盒版猜是地獄難度。

## 檔案

```
index.html     試聽台（HTML + JS，單檔）
musician.js    合成引擎（三音色＋和聲＋排程）
config.js      所有數值與曲庫（改完存檔、重整網頁即生效）
strings.zh.js  介面文字
```
